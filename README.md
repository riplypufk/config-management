# Эмулятор командной оболочки — этапы 1–4

## Описание проекта

Учебный проект эмулятора командной оболочки UNIX-подобной операционной системы на Python.

Программа предоставляет консольный интерфейс (CLI), поддерживает разбор команд, раскрытие переменных окружения, обработку ошибок, запуск команд из стартового скрипта и работу с виртуальной файловой системой (VFS), хранящейся в ZIP-архиве.

## Требования

- Python 3
- macOS, Linux или другая ОС с поддержкой Python 3
- Zsh или Bash для запуска shell-скриптов

## Реализованные возможности

### Этап 1. REPL

- Консольный интерфейс для взаимодействия с эмулятором.
- Приглашение с именем VFS.
- Раскрытие переменных окружения, например `$HOME`.
- Команда `exit` для завершения работы.
- Обработка неизвестных команд и неверных аргументов.
- Обработка ошибок разбора команд.

### Этап 2. Конфигурация

- Параметр `--vfs` для указания пути к ZIP-архиву виртуальной файловой системы.
- Параметр `--script` для указания стартового скрипта.
- Вывод параметров запуска.
- Последовательное выполнение команд из файла.
- Отображение выполняемых команд.
- Остановка стартового скрипта при первой ошибке.
- Обработка ошибок чтения стартового скрипта.
- Скрипты для проверки разных вариантов запуска.

### Этап 3. Виртуальная файловая система

- Загрузка виртуальной файловой системы из ZIP-архива.
- Хранение структуры каталогов и файлов в памяти.
- Обработка файлов и каталогов при загрузке архива.
- Проверка путей внутри ZIP-архива.
- Сохранение виртуальной файловой системы в ZIP-архив с помощью команды `vfs-save`.
- Поддержка тестирования с разными вариантами виртуальных файловых систем.
- Тестовые архивы для проверки минимальной файловой системы, нескольких файлов и вложенной структуры каталогов.

### Этап 4. Команды

- `ls` — вывод содержимого текущего или указанного каталога VFS.
- `cd` — переход в указанный каталог VFS.
- `cd ..` — переход в родительский каталог.
- `cd` без аргументов — переход в корень VFS.
- `pwd` — вывод пути текущего каталога.
- `history` — отображение истории введённых команд.
- Проверка количества и корректности аргументов команд.
- Обработка ошибок при обращении к несуществующим каталогам и при попытке перейти в файл.
- Стартовый скрипт для проверки основных команд, работы с VFS и обработки ошибок.

## Запуск

Обычный интерактивный запуск:

```bash
python3 src/main.py
```

Или через скрипт запуска:

```bash
./run.sh
```

Показать справку:

```bash
python3 src/main.py --help
```

## Запуск с параметрами

Указать путь к VFS:

```bash
python3 src/main.py --vfs tests/fixtures/vfs_minimal.zip
```

Указать стартовый скрипт:

```bash
python3 src/main.py --script scripts/startup.txt
```

Указать VFS и стартовый скрипт:

```bash
python3 src/main.py --vfs tests/fixtures/vfs_nested.zip --script scripts/startup.txt
```

Запустить тестовый скрипт этапа 4:

```bash
python3 src/main.py --vfs tests/fixtures/vfs_nested.zip --script scripts/startup_stage4.txt
```

## Основные команды

| Команда | Назначение |
|---|---|
| `ls` | Показать содержимое текущего каталога |
| `ls /docs` | Показать содержимое указанного каталога |
| `cd /docs` | Перейти в указанный каталог |
| `cd ..` | Перейти в родительский каталог |
| `cd` | Перейти в корень VFS |
| `pwd` | Показать текущий путь |
| `history` | Показать историю команд |
| `vfs-save archive.zip` | Сохранить VFS в ZIP-архив |
| `exit` | Завершить работу эмулятора |

Пути обрабатываются внутри виртуальной файловой системы. Команды `ls`, `cd` и `pwd` не предназначены для просмотра и изменения реальной файловой системы компьютера.
