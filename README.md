# Эмулятор командной оболочки — этапы 1–5

## Описание проекта

Учебный проект эмулятора командной оболочки UNIX-подобной операционной системы на Python.

Программа предоставляет консольный интерфейс (CLI), поддерживает разбор команд, раскрытие переменных окружения, обработку ошибок, выполнение стартовых скриптов и работу с виртуальной файловой системой (VFS), хранящейся в ZIP-архиве.

Виртуальная файловая система загружается в память, а изменения её содержимого могут сохраняться в ZIP-архив без непосредственного изменения файлов на хостовой операционной системе.

## Требования

- Python 3
- macOS, Linux или другая ОС с поддержкой Python 3

## Реализованные возможности

### Этап 1. REPL

- Консольный интерфейс с интерактивным вводом команд.
- Приглашение с именем виртуальной файловой системы.
- Раскрытие переменных окружения, например `$HOME`.
- Начальная реализация команд `ls` и `cd`.
- Команда `exit` для завершения работы.
- Обработка неизвестных команд и неверных аргументов.
- Обработка ошибок разбора команд.

### Этап 2. Конфигурация и стартовые скрипты

- Параметр `--vfs` для указания ZIP-архива виртуальной файловой системы.
- Параметр `--script` для указания стартового скрипта.
- Вывод параметров запуска.
- Последовательное выполнение команд из файла.
- Отображение выполняемых команд и результатов.
- Остановка выполнения стартового скрипта при первой ошибке.
- Скрипты для проверки различных вариантов запуска.

### Этап 3. Виртуальная файловая система

- Загрузка виртуальной файловой системы из ZIP-архива.
- Представление файлов и каталогов в памяти.
- Обработка структуры каталогов и содержимого файлов.
- Сохранение виртуальной файловой системы в ZIP-архив с помощью команды `vfs-save`.
- Поддержка нескольких тестовых архивов с различным содержимым.
- Автоматизированные скрипты для проверки загрузки и сохранения VFS.

### Этап 4. Навигация и история команд

- Реализация команды `ls` для просмотра содержимого текущего каталога.
- Реализация команды `cd` для перехода между каталогами.
- Реализация команды `pwd` для вывода текущего пути.
- Реализация команды `history` для просмотра истории команд.
- Работа с путями внутри виртуальной файловой системы.

### Этап 5. Изменение виртуальной файловой системы

- Реализация команды `touch` для создания файлов.
- Реализация команды `mv` для перемещения и переименования файлов.
- Изменение содержимого VFS в памяти без непосредственного изменения файлов хостовой системы.
- Сохранение изменений в ZIP-архив с помощью команды `vfs-save`.

## Запуск

Обычный интерактивный запуск:

```bash
python3 src/main.py
```

Или с помощью скрипта:

```bash
./run.sh
```

Просмотр справки:

```bash
python3 src/main.py --help
```

## Запуск с параметрами

Указать ZIP-архив виртуальной файловой системы:

```bash
python3 src/main.py --vfs tests/fixtures/vfs_minimal.zip
```

Указать стартовый скрипт:

```bash
python3 src/main.py --script scripts/startup.txt
```

Указать оба параметра:

```bash
python3 src/main.py --vfs tests/fixtures/vfs_minimal.zip --script scripts/startup.txt
```

## Команды эмулятора

| Команда         | Назначение                             |
| --------------- | -------------------------------------- |
| `ls`            | Просмотр содержимого текущего каталога |
| `cd`            | Переход в другой каталог               |
| `pwd`           | Вывод текущего пути                    |
| `history`       | Просмотр истории команд                |
| `touch`         | Создание файла                         |
| `mv`            | Перемещение или переименование файла   |
| `vfs-save PATH` | Сохранение VFS в ZIP-архив             |
| `exit`          | Завершение работы эмулятора            |

Поддерживаемые аргументы и ограничения команд определяются реализацией эмулятора.

## Тестирование

Скрипты запускаются из корневой папки проекта.

Проверка стандартного запуска:

```bash
./scripts/test_default.sh
```

Проверка выполнения стартового скрипта:

```bash
./scripts/test_script.sh
```

Проверка виртуальных файловых систем:

```bash
./scripts/test_vfs_minimal.sh
./scripts/test_vfs_multiple.sh
./scripts/test_vfs_nested.sh
```

### Тестовые архивы

- `vfs_minimal.zip` — минимальная виртуальная файловая система.
- `vfs_multiple.zip` — виртуальная файловая система с несколькими файлами.
- `vfs_nested.zip` — виртуальная файловая система с вложенными каталогами.

Стартовый скрипт `scripts/startup.txt` используется для последовательной проверки команд эмулятора и обработки ошибок.
