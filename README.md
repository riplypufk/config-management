# Эмулятор командной оболочки — этапы 1–3

## Описание проекта

Учебный проект эмулятора командной оболочки UNIX-подобной операционной системы на Python.

Программа предоставляет консольный интерфейс (CLI), поддерживает разбор команд, раскрытие переменных окружения, обработку ошибок, запуск команд из стартового скрипта и работу с виртуальной файловой системой, хранящейся в ZIP-архиве.

## Требования

* Python 3
* macOS, Linux или другая ОС с поддержкой Python 3

## Реализованные возможности

### Этап 1. REPL

* Консольный интерфейс.
* Приглашение с именем VFS.
* Раскрытие переменных окружения, например `$HOME`.
* Команды `ls` и `cd` в виде заглушек.
* Команда `exit`.
* Обработка неизвестных команд и неверных аргументов.
* Обработка ошибок разбора команд.

### Этап 2. Конфигурация

* Параметр `--vfs` для указания пути к ZIP-архиву.
* Параметр `--script` для указания стартового скрипта.
* Вывод параметров запуска.
* Последовательное выполнение команд из файла.
* Отображение команд и результатов выполнения.
* Остановка стартового скрипта при первой ошибке.
* Скрипты для проверки разных вариантов запуска.

### Этап 3. Виртуальная файловая система

* Загрузка виртуальной файловой системы из ZIP-архива.
* Хранение структуры каталогов и файлов в памяти.
* Обработка файлов и каталогов при загрузке архива.
* Сохранение виртуальной файловой системы в ZIP-архив с помощью команды `vfs-save`.
* Поддержка тестирования с разными вариантами виртуальных файловых систем.
* Тестовые архивы для проверки минимальной файловой системы, нескольких файлов и вложенной структуры каталогов.
* Скрипты автоматического запуска эмулятора для проверки тестовых архивов.

## Запуск

Обычный интерактивный запуск:

```bash
python3 src/main.py
```

Или через скрипт:

```bash
./run.sh
```

Показать справку:

```bash
python3 src/main.py --help
```

## Запуск с параметрами

Указать путь к VFS:

```bash
python3 src/main.py --vfs tests/fixtures/vfs_minimal.zip
```

Указать стартовый скрипт:

```bash
python3 src/main.py --script scripts/startup.txt
```

Указать оба параметра:

```bash
python3 src/main.py --vfs tests/fixtures/vfs_minimal.zip --script scripts/startup.txt
```

## Тестирование

Скрипты запускаются из корневой папки проекта.

Проверка стандартного запуска и возможностей предыдущих этапов:

```bash
./scripts/test_default.sh
./scripts/test_script.sh
```

Проверка загрузки и сохранения виртуальной файловой системы:

```bash
./scripts/test_vfs_minimal.sh
./scripts/test_vfs_multiple.sh
./scripts/test_vfs_nested.sh
```

Тестовые архивы находятся в `tests/fixtures/`:

* `vfs_minimal.zip` — минимальная виртуальная файловая система.
* `vfs_multiple.zip` — виртуальная файловая система с несколькими файлами.
* `vfs_nested.zip` — виртуальная файловая система с вложенными каталогами и файлами.

Стартовый скрипт `scripts/startup.txt` используется для последовательной проверки команд эмулятора, включая сохранение виртуальной файловой системы.
