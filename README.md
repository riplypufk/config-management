# Эмулятор UNIX-подобной оболочки

## Общее описание
Консольный эмулятор командной оболочки UNIX-подобной ОС.
На первом этапе реализован REPL-интерфейс, парсинг команд,
раскрытие переменных окружения и команды-заглушки.

## Команды

### ls
Выводит имя команды.
Аргументы считаются ошибкой.

Пример:
ls

### cd
Выводит команду и переданный аргумент.

Пример:
cd folder

### exit
Завершает работу эмулятора.

Пример:
exit

## Переменные окружения
Поддерживается раскрытие переменных окружения реальной ОС.

Пример:
cd $HOME

## Запуск
```bash
./run.sh
